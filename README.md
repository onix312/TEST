# GameDev AI Office

Локальная Windows-панель разработки Unity-игры с Codex и ручным импортом утверждённого GDD из ChatGPT.

## Запуск

Установите Python 3.11, Unity Editor, Codex CLI (`codex login`). Скачайте репозиторий и запустите `start.bat`. В приложении укажите корень Unity-проекта, путь к Unity.exe, импортируйте GDD в `.md` и отправляйте задачи Codex.

Работа без Git; задачи выполняются последовательно. Сделайте резервную копию Unity-проекта перед использованием. Запросы Codex могут менять файлы в соответствии с его настройками разрешений.

**Статус:** ранний прототип. Прямое управление существующим чатом ChatGPT, Pixel Office, безопасные изолированные копии, полноценный orchestration и готовый инсталлятор ещё не реализованы.
