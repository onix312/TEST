# GameDev AI Office — Unity + ChatGPT Game Designer + Codex

Локальная Windows-программа для разработки Unity-игр. **Git не обязателен.**

- **ChatGPT (твой существующий чат)** — Game Designer: вопросы, обсуждение и согласование GDD. Открытый чат ChatGPT не предоставляется стороннему приложению автоматически; используем экспорт утверждённого Markdown.
- **GameDev AI Office** — хранение утверждённого GDD, планирование задач, управление агентами и Unity.
- **Codex CLI** — до четырёх параллельных разработчиков, каждый в собственной копии Assets/Packages/ProjectSettings.
- **Unity Bridge** — создание сцены по JSON, отчёт о сцене, EditMode/PlayMode тесты, Play Mode screenshot из меню Unity и Windows-сборка.
- **Pixel Office и Mini Island** — интерактивный офис **строго сверху (top-down, 90°)**, а не изометрия или вид сбоку; реальный статус моделей и агентов.
- Нажатие на рабочее место открывает задачу, результат и ошибки в соседней панели. Можно перемещать камеру мышью, масштабировать колесом, создавать задачи и запускать оркестр с главного экрана.

## Как установить на Windows

1. Установи Unity Hub/Unity Editor с поддержкой Windows Build Support и создай или открой Unity-проект.
2. Установи [Codex CLI](https://github.com/openai/codex#quickstart) для Windows. В терминале выполни `codex login`, выбери **Sign in with ChatGPT**. Альтернатива: `npm install -g @openai/codex` при установленном Node.js.
3. Перейди в [Actions → Windows portable and installer](https://github.com/onix312/TEST/actions/workflows/windows.yml). После успешного запуска workflow открой последний run, скачай артефакт **GameDevAIOffice-Windows-Setup** и запусти EXE-установщик. Для запуска без установки есть Portable.
4. В приложении открой **Настройки**, укажи корень Unity-проекта, выбери Unity.exe (автоопределение доступно), проверь команду Codex и нажми **Сохранить и подключить проект**.
5. Во вкладке **Game Designer / GDD** нажми **Скопировать запрос для ChatGPT**, отправь его в существующий чат Game Designer, возьми *утверждённый* GDD, нажми «GDD из буфера» (или импортируй Markdown), затем отдельно «Утвердить содержимое редактора».
6. Перейди в **Codex Agents**: создай задачу, либо нажми «Запрос плана для ChatGPT», отправь запрос в существующий чат и нажми «Вставить план ChatGPT» после копирования JSON. Отдельный API-планировщик тоже доступен. Запусти агентов. Изменения без конфликтов могут применяться автоматически; конфликты/удаления — после просмотра.
7. Во вкладке **Unity** нажми **Установить Unity Bridge**, закрой Unity Editor перед batch-операциями, используй команды «Создать сцену», «Unity EditMode / PlayMode», «Собрать Windows Game».

**Python и Node.js для самого установщика не нужны.** Unity и Codex — отдельные приложения, их нужно установить/авторизовать. API-ключ для планировщика необязателен: без него задачи добавляются вручную и Codex продолжает работать через собственный вход.

### Режим без установщика

На Windows с Python 3.11 распакуй/клонируй репозиторий и запусти `start.bat`. Скрипт создаст виртуальное окружение и установит PySide6.

## Что происходит с файлами игры

Проект остаётся в выбранной папке на твоём ПК. GameDev AI Office создаёт:

- `.ai-office/gdd/approved.md` — утверждённые требования. Старые редакции хранятся рядом.
- `.ai-office/tasks.json` — список задач, зависимости, статусы.
- `.ai-office/workspaces/<task>/project/` — изолированные рабочие копии Codex.
- `.ai-office/checkpoints/` — ZIP-снимки Assets/Packages/ProjectSettings перед переносом изменений.
- `.ai-office/logs/` — события Codex, `.ai-office/reports/` — отчёты Unity.
- `.ai-office/designer-chat.json` — сообщения отдельного API Game Designer (если используешь).

Codex не получает путь к исходному Unity-проекту в своих заданиях: он работает с копией; диспетчер сверяет SHA-256 файлов и предотвращает случайное затирание конкурирующих изменений. **При удалениях требуется отдельное подтверждение.** Архивы резервных точек восстанавливаются вручную при закрытом Unity Editor. Рабочие копии и checkpoints занимают место на диске.

## Оркестрация ChatGPT + Codex

**Автоматическая маршрутизация** выбирается в **Codex Agents → Исполнитель → Авто**:

| Задача | Исполнитель | Итог |
| --- | --- | --- |
| Названия предметов, диалоги, краткие описания, списки идей | ChatGPT Luna (через OpenAI API) | Текстовый отчёт для следующих задач |
| Анализ баланса, связей систем, текстовое техническое ТЗ | ChatGPT Sol (через API) | Аналитическая записка |
| Сложный разбор игровых систем | ChatGPT Astra (выбрать вручную) | Подробный отчёт |
| C#-скрипты, сцены, префабы, изменение Unity-файлов | Codex CLI | Изменения в изолированной копии, безопасное применение |
| Проверка предложенного Codex-кода | Отдельная ChatGPT-модель (опция) | `APPROVE` или `BLOCK` до автоприменения |

Автоопределение — консервативные правила по тексту задачи. При сомнении используется Codex; пользователь всегда может явно выбрать исполнителя. ChatGPT в автоматическом режиме **не редактирует Unity-проект напрямую**: его отчёт сохраняется в `.ai-office/reports/<id>-chatgpt.md`, и автоматически передаётся зависимым задачам. Чтобы превратить готовый отчёт в код, выбери **«Результат → задача Codex»**.

Сложные запросы можно разбить кнопкой **«AI → план»**: модель создаст граф задач с маршрутами `chatgpt_fast`, `chatgpt_balanced` и `codex`. Система сохраняет зависимости; Codex не начинает задачу до завершения её ChatGPT-предшественника.

**Без API-ключа:** ChatGPT-задачи попадают в статус «ЖДЁТ CHATGPT». Выбери такую задачу, нажми **«Задание → ChatGPT»**, вставь запрос в существующий Game Designer чат, затем скопируй ответ и нажми **«Ответ ChatGPT ← буфер»**. После принятия отчёта снова нажми «Запустить агентов», чтобы продолжить зависимые задачи. Для постоянной автоматической работы ChatGPT через API потребуется свой ключ и отдельная тарификация.

**С API-ключом:** модельные текстовые задачи выполняются автоматически в пределах до четырёх параллельных слотов, без дополнительных файловых прав. В настройках можно указать модели: быстрый `gpt-6-luna`, аналитик `gpt-6.1-sol`, эксперт `gpt-6-astra`, ревьюер (по умолчанию Sol). Поддержка зависит от доступа аккаунта OpenAI API. Отдельный API-ключ не требуется для Codex CLI, если он авторизован поддерживаемым способом.

**Модельное ревью:** по умолчанию выключено. Если включить **«AI-ревью перед слиянием»**, отдельная модель читает отрывки изменённых файлов и сравнивает их с утверждённым GDD. При `BLOCK` или ошибке модели автоматическое применение блокируется; человек может просмотреть изменения и применить их вручную. Это не замена компиляции или тестам Unity, а дополнительный контроль.

### Кто за что отвечает

- **ChatGPT Game Designer (существующий чат)** — обсуждение игрового дизайна, принятие решений только после согласования с тобой, GDD.
- **ChatGPT Luna/Sol/Astra (API или ручной обмен)** — лёгкие вспомогательные задачи, текст, исследование в пределах предоставленного контекста, планирование, необязательное ревью.
- **Codex CLI** — внесение изменений в локальные файлы Unity и подготовка реализации.
- **GameDev AI Office** — очередь, зависимости, маршруты моделей, хранение результатов, проверка конфликтов и откат.

Модели не читают твои облачные ChatGPT-чаты автоматически. GDD отправляется в API только для задач, где выбран API-маршрут. Подписка ChatGPT и использование OpenAI API — разные способы доступа.

## ChatGPT Game Designer

Существующий чат ChatGPT и API — **две разные сессии**. Не существует универсального поддерживаемого способа автоматически прочитать произвольный открытый чат ChatGPT из локальной программы. Поэтому основной гарантированный обмен — утверждённый Markdown GDD.

Вкладка Game Designer также предлагает **дополнительный** чат по OpenAI Responses API и декомпозицию задач. Бесплатный по API-части (без дополнительных API-запросов из нашей программы) режим работает через буфер обмена: «Запрос плана для ChatGPT» → ChatGPT → «Вставить план ChatGPT». Для этого задай `OPENAI_API_KEY` в окружении или введи ключ в настройках на текущую сессию. API оплачивается отдельно от подписки ChatGPT; ключ нигде не сохраняется.

## Безопасность, ограничения

- Программа не меняет локальную игру прямо во время работы агентов; изменения применяются после сверки с исходным состоянием и создания архивной точки.
- Два агента, изменившие один файл, получают конфликт: приложение не выбирает победителя автоматически. Открой их рабочие папки для ручного разрешения.
- Автоматическое восстановление после незавершённого переноса не реализовано. После аварийного выключения проверь основной проект и резервную копию.
- Для batch-операций Unity проект нельзя одновременно держать открытым в редакторе.
- Создание 3D-моделей, автоматическое прохождение игры, восприятие Game View и глубокие визуальные тесты не являются частью этой версии.
- **Реальная работа на пользовательском Windows/Unity окружении ещё не проверена.** Ни прохождение тестов, ни успешность сборки инсталлятора в данный момент не заявляются. Исходники размещены в feature-ветке/PR #1.

## Описание модулей

`main.py` — UI; `office_core.py` — состояние и GDD; `agents.py` — Codex и DAG; `orchestra.py` — диспетчер моделей; `model_routing.py` — маршруты; `workspaces.py` — снимки/слияние; `director.py` — OpenAI API; `unity_integration.py` и `unity_bridge/` — Unity; `pixel_office.py` — пиксельный офис; `installer.iss` — Windows Setup.

## Главный экран — Pixel Office Top-down

Планировка нарисована средствами Qt, внешние картинки и сетевое подключение для отображения офиса не нужны. Игровой офис показывает рабочие столы разработчиков, комнату Game Designer/GDD и Unity/QA-зону. Состояния берутся из реального списка задач, поэтому офис не отображает выдуманные проценты выполнения.

**Управление:** колесо — масштабирование, перетаскивание левой кнопкой — перемещение камеры, двойной клик по свободному полу или кнопка «Центрировать камеру» — возврат, клик по персонажу — выбор задания. Справа показаны статус, модель, текст задачи и отчёт; можно перейти к полному просмотру или передать подходящую задачу ChatGPT. Внизу главного экрана — поле быстрого создания задач с автоматическим выбором модели.

На слабом ПК отрисовку можно дополнительно оптимизировать при последующем тестировании реальной Windows-сборки.

### Pixel Office 2.1: движения и очередь

Персонажи теперь перемещаются по полу строго сверху, когда меняется состояние задачи: ChatGPT-задача, ожидающая передачи, направляется в зону GDD; ошибки и запросы проверки — в Unity/QA, обычная разработка — к рабочим столам. Анимация отображает переход состояния, но не означает реального физического действия в Unity. Сверху сцены показана очередь до пяти реальных ожидающих задач; карточки кликабельны. Контекстная панель показывает зависимости выбранной задачи. При включённом режиме снижения анимации персонажи сразу появляются в целевой зоне.
